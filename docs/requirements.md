# Requirements

## 产品定位

LithiumCraft 第一版是内部投研情报工作台，不是公开门户网站。目标用户是内部研究、投资、技术分析人员，用于跟踪锂电池工艺、产业链、政策、企业动态、技术资料和媒体信息。

## 一期目标

- 统一 Vue 工作台，全站登录后使用。
- 精选 5-10 个公开合规来源，默认低频自动抓取。
- 抓取后完成去重、AI 摘要、标签、分类、重要性评分和风控过滤。
- 正常内容进入内部情报库，异常内容标记为 `blocked`。
- 支持情报检索、分类筛选、详情查看和归档。
- 支持每日摘要，按日期聚合新增情报。
- 支持来源管理、抓取日志和系统设置。

## 非目标

- 不做公开 SEO 门户。
- 不做外部用户注册体系。
- 不做付费会员、App、小程序、报告自动生成和完整企业库。
- 不做大规模分布式爬虫。
- 不抓取登录、付费墙、验证码后、非公开接口或被禁止抓取的内容。

## 内容来源

第一期只自动抓取，不做手动录入。来源配比均衡覆盖公告/政策、行业媒体、技术资料三类，每类 2-3 个源。任何不确定合规性的来源默认禁用。

## 权限

第一期使用单管理员账号。除 `/health` 和 `/api/v1/auth/login` 外，所有业务 API 都需要 Bearer JWT。
