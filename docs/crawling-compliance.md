# Crawling Compliance

## 允许行为

- 抓取公开可访问页面、公开 RSS、公开 API、公开 sitemap。
- 在来源配置中明确来源类型、域名、抓取频率、单次页数和每日上限。
- 使用明确 User-Agent，并保留抓取日志。

## 禁止行为

- 不抓取登录后内容、付费墙内容、验证码后内容、内网或非公开接口。
- 不绕过反爬，不破解验证码，不伪造登录，不使用代理池轰炸。
- 不采集个人隐私数据。
- 不抓取 `robots.txt` 禁止的 URL。

## 限频规则

每个域名设置访问间隔、超时、失败重试次数、单次最大页数和每日上限。第一期自动调度固定为每天 `Asia/Shanghai 07:00` 抓取全部启用来源；管理员手动抓取用于小范围验证和补抓，不能替代来源合规确认。

## 展示边界

公开前台只展示 `active` 情报的标题、摘要、关键字段、来源名称、原文链接和时间戳；`blocked`、`archived` 等非公开展示状态仅供管理员查看或处理。不全文搬运受版权保护内容，不用演示情报或虚构来源填充首页。
