# Crawling Compliance

LithiumCraft 只做锂电池制造工艺知识库。抓取目标是公开来源中的工序资料、规范说明、技术科普和研究机构公开内容，不抓非工艺新闻、投融资、价格行情或企业动态。

## 允许行为

- 抓取公开可访问页面、公开 RSS、公开 API、公开 sitemap，且必须先通过 `robots.txt` 检查。
- 来源候选必须记录域名、入口 URL、来源类型、目标工序、robots 状态和人工确认备注。
- 所有新增候选来源默认 `manual_only` 或 `disabled`；只有人工确认入口、详情页和图片 URL 均允许后，才可改为 `enabled`。
- 使用明确 User-Agent，遵守 `Crawl-delay`；若 robots 未声明延迟，则使用系统域名限频配置。
- 抓取日志需记录 robots 检查结果、被拒绝 URL、抓取数量、图片数量和失败原因。

## 禁止行为

- 不抓登录页、付费墙、验证码页、附件下载区、站内搜索结果页、反爬提示页。
- 不绕过反爬，不破解验证码，不伪造登录，不使用代理池轰炸。
- 不采集个人隐私数据，不下载受限附件，不抓取 `robots.txt` 禁止的 URL。
- 如果入口 URL 返回 `robots_disallow`，必须立即停止该来源，将来源标记为 `blocked_by_policy`，不得自动恢复为 `enabled`。
- 如果详情页 URL 被 robots 禁止，只跳过该条资料，不入库。
- 如果图片 URL 被 robots 禁止，资料可以入库，但不得展示外部图片，改用站内示意图。

## 工艺内容规则

- 抓取结果必须命中制造工艺关键词包后才进入公开资料库。
- 当前工序范围：制浆、涂布、辊压、分切、卷绕/叠片、装配、注液、化成、分容、检测。
- 入库字段只保存标题、摘要、正文摘录、来源、发布时间、关键词、原文链接和抓取时间。
- 不全文搬运外部内容，不用演示资料或虚构来源填充页面。

## 图片展示规则

- 优先使用站内原创示意图或图标解释工序流程，降低版权风险。
- 外部图片只可作为合规缩略图使用，且必须同时满足：
  - 图片 URL robots 允许抓取；
  - 图片来自同一公开页面或页面明确引用；
  - 不绕过防盗链、不下载受限图片；
  - 前台标明来源并链接原文。
- 无法确认图片合规时，不展示外部图片，使用站内工序示意图占位。

## 调度与启用

自动调度固定为每天 `Asia/Shanghai 07:00` 抓取全部 `enabled` 来源。`manual_only` 只允许管理员手动验证，不参与自动调度。每日自动抓取前仍需重新检查 robots，避免来源规则变化后继续访问。

管理员手动抓取用于小范围验证和补抓，不能替代来源合规确认。任何来源一旦被标记为 `blocked_by_policy`，应先重新人工审核 robots 和页面条款，再决定是否重新添加新的候选来源。
